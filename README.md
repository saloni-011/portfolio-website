# 🚀 Personal Portfolio Website — Saloni

A sleek, modern, and fully responsive developer portfolio built for the **Valentius Kryptix Internship Program (WA-1 Task)**. Crafted with raw **HTML5**, **Tailwind CSS**, and **Vanilla JavaScript** (zero framework dependencies).

---

## ✨ Features & Highlights

- **⚡ Modern UI/UX**: Glassmorphic elements, glowing spotlights, 3D tilt card hover effects, and interactive canvas particle background.
- **📱 Fully Responsive**: Custom-built mobile drawer navigation and optimized layouts tested at `375px` (Mobile), `768px` (Tablet), and `1280px+` (Desktop).
- **♿ Semantic & Accessible HTML**: HTML5 structural elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`) with ARIA attributes and structured data.
- **🌙 Theme Switcher**: Instant Dark/Light mode toggle with `localStorage` state persistence.
- **🔍 Interactive Project Showcase**: Categorized filtering system (All, Web, Apps, AI) with interactive detail preview modals.
- **💻 Interactive Developer Terminal**: Built-in CLI supporting commands like `help`, `about`, `skills`, `projects`, and `contact`.
- **📄 Resume Preview Modal**: Embedded interactive CV reader with direct print and download options.
- **✉️ Interactive Contact Form**: Real-time form validation, visual character counting, and toast notifications.
